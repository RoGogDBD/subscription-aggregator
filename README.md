# Subscription Aggregator API

REST сервис для агрегации онлайн-подписок.

---

## Описание

Данный сервис предоставляет REST API для управления подписками пользователей на различные онлайн-сервисы. Позволяет создавать, получать, обновлять и удалять подписки, а также рассчитывать общую стоимость подписок за указанный период.

---
## Запуск проекта

```bash
docker-compose up -d
```
---
## API

Для более детального описания смотрите [Swagger UI](http://localhost:8080/swagger/index.html)

---
## Миграции базы данных
Миграции выполняются автоматически при запуске сервиса через Docker Compose.

---
## Логирование
Сервис логирует все входящие HTTP запросы и ошибки в стандартный вывод (stdout). Уровень логирования можно настроить через переменную окружения LOG_LEVEL.
